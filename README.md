# 目标记录看板

把目标会话里每一轮的最终回答显示到右栏看板。一条记录对应一轮，列表只显示这轮回答的第一段；点一下记录，在板内展开完整回答。看板不调用模型，也不要求模型额外写一份总结。

## 安装

包名：`@wastee/dsh-goal-record-board`

要求 DSH 版本在 `>=0.2.0 <0.3.0` 范围内。

### 方式一：图形界面（推荐）

1. 打开 DSH，进入左侧栏底部的**插件**。
2. 点击**添加插件**，选择**安装第三方插件**。
3. 在**包名或地址**里填入 `@wastee/dsh-goal-record-board`；安装包默认从**默认安装源**（npm 官方源）下载，需要时可在**安装源**里切换成其他源。
4. 点击**安装**，在**安装插件**确认框里核对包名后确认。
5. 装好后，在同一页的**已安装**里找到"目标记录看板"，打开开关启用。若提示需要重启，按提示重启 DSH。

> 只在插件页看到安装入口还不够，记得启用插件并新开一个会话，入口才会出现。

### 方式二：命令行

```sh
dsh plugin add @wastee/dsh-goal-record-board
```

装完后在**插件**页启用；如果当前 profile 是新初始化的，按提示重启 DSH。

## 用法

1. 当前会话有目标时，会话标题栏会出现一个清单图标的按钮，鼠标悬停时显示“目标记录看板”。点击后在右侧栏打开“目标记录看板”页签；没有目标的会话不显示这个按钮。
2. 打开看板后，先显示最近 10 个轮次。同一轮只占一条记录；一轮有多条助手消息时，以最后一条带文字的助手消息作为这一轮的最终回答。总共不足 10 轮时全部显示。顶部一行计数：部分显示时写“已显示 X / M 轮”，全部显示后写“共 M 轮”。轮数按不同的轮次分组统计；取不到轮次的记录显示为“轮次未知”，也占一组。计数行的数字变化会被屏幕阅读器读出来。
3. 记录按轮次分组，最新的一轮排在最上面。组标题写“第 N 轮”；这一轮最新的记录不在今天时，组标题右侧再补上日期（月-日）。
4. 每条记录只显示最终回答的第一段。第一段按空行划分；回答里没有空行时，整段就是第一段，也没有可展开的内容。点第一段文字，或点下面的“展开全文”，在记录里显示完整回答；再点“收起”回到第一段。展开和收起只改变页面显示。
5. 展开后的完整回答保留换行，文字长时自动换行，可以直接选中复制。
6. 还有更早的轮次时，列表末尾显示“加载更多”按钮，跟着列表一起滚动。点一次继续显示后面的 10 轮；剩下的不足 10 轮时一次显示完；已经显示的内容不动，焦点落到新出现的第一份报告上。“加载更多”可以用 Tab 选中，按 Enter 或空格触发。
7. 全部轮次显示完后，“加载更多”按钮消失，列表末尾显示“没有更早的记录了”。如果第一批就包含全部轮次，不显示按钮，也不显示这条提示。
8. 看板在页签内部自己滚动。记录多时，先显示最近 10 轮，点“加载更多”继续往前看，可以一直翻到最早一轮；最底部的记录能完整看到；滚动时当前这一轮的组标题固定在顶部。
9. 看板开着时新产生的记录会出现在最上面，并短暂高亮一次；计数行跟着更新，已经看到的更早轮次不会被挤掉。
10. 切到别的页签再回来，或关掉再打开看板，会重新从第一批开始显示。
11. 没有记录时，看板显示空状态提示，不显示计数行，也没有“加载更多”按钮和“没有更早的记录了”提示。

## 数据从哪来

记录来自会话日志里的助手消息（`assistant/message` 事件）。看板按轮次保留最后一条带文字的助手消息，作为这一轮的最终回答；看板从日志中派生出列表，不写入第二份存储。因此刷新、分叉或重放会话后，记录仍然可以从日志重建。记录列表仍然一次发给浏览器，分批显示只影响页面上画多少轮，不改日志和投影格式。

看板不调用模型：列表的第一段和展开后的全文都来自已经生成的最终回答，看板不额外生成总结。最终回答本身仍然是正常回复，照常消耗模型 token；看板这部分不增加模型调用。

1.0.3 起，旧版的 `goal_record` 工具已经移除，也不兼容旧数据。旧的 `goal_record` 调用不显示；看板只从助手最终回答取数，所以旧轮次只要日志里有助手最终回答，仍会以最终回答的形式出现。

## 关闭插件后

关闭插件不会删除任何日志记录。看板页签和标题栏按钮会一并消失；重新启用后，看板会从会话日志里的助手最终回答重新构建。

## 字体与图标

界面继承 DSH 的主题变量，不打包任何字体文件。插件图标为原创图形。
