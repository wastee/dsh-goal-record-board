# 目标记录看板

把当前目标每个轮次的三项内容记录到右栏看板：遇到的问题、采用的方案、取得的成果。每条记录折叠成一行，点击展开后可以看到完整内容。

## 安装

包名：`@wastee/dsh-goal-record-board`

要求 DSH 版本在 `>=0.2.0 <0.3.0` 范围内。

### 方式一：图形界面（推荐）

1. 打开 DSH，进入左侧栏底部的**插件**。
2. 点击**添加插件**，选择**安装第三方插件**。
3. 在**包名或地址**里填入 `@wastee/dsh-goal-record-board`；安装包默认从**默认安装源**（npm 官方源）下载，需要时可在**安装源**里切换成其他源。
4. 点击**安装**，在**安装插件**确认框里核对包名后确认。
5. 装好后，在同一页的**已安装**里找到"目标记录看板"，打开开关启用。若提示需要重启，按提示重启 DSH。

> 只在插件页看到安装入口还不够，记得启用插件并新开一个会话，入口才会出现。

### 方式二：命令行

```sh
dsh plugin add @wastee/dsh-goal-record-board
```

装完后在**插件**页启用；如果当前 profile 是新初始化的，按提示重启 DSH。

## 用法

1. 当前会话有目标时，会话标题栏会出现一个清单图标的按钮，鼠标悬停时显示"目标记录看板"。点击后在右侧栏打开"目标记录看板"页签；没有目标的会话不显示这个按钮。
2. 打开看板后，先显示第一批记录：取最近的若干整轮，累计不少于 10 条记录；同一轮的记录不拆开，所以这一批可能略多于 10 条，某一轮记录特别多时列表也会跟着变长。总共不足 10 条时全部显示。顶部一行条数：部分显示时写"已显示 X / N 条记录 · M 轮"，全部显示后写"N 条记录 · M 轮"。轮数按不同的轮次号统计；轮次未知的记录只计入条数，不计入轮数。条数行的数字变化会被屏幕阅读器读出来。
3. 记录按轮次分组，最新的一轮排在最上面。组标题写"第 N 轮"；这一轮最新的记录不在今天时，组标题右侧再补上日期（月-日）。
4. 每条记录默认折叠成一行，从左到右是时间和这条记录的问题摘要。摘要取问题一段的内容，把换行压成空格，太长时在末尾省略；问题为空时改显示成果的摘要。
5. 点击一行，在这行下方直接显示问题、方案、成果三段全文，长文字不截断，也不需要再点第二次；再点一次同一行收起。
6. 焦点在展开的记录里时，按 Esc 收起这条记录，焦点回到这一行的按钮上。
7. 还有更早的记录时，列表末尾显示"加载更多"按钮，跟着列表一起滚动。点一次继续显示后面的整轮，每次新增至少 10 条，剩下的不足 10 条时一次显示完；已经展开的行保持展开，焦点落到新出现的第一行。"加载更多"可以用 Tab 选中，按 Enter 或空格触发。
8. 全部记录显示完后，"加载更多"按钮消失，列表末尾显示"没有更早的记录了"。如果第一批就包含全部记录，不显示按钮，也不显示这条提示。
9. 看板在页签内部自己滚动。记录多时，先显示最近几轮，点"加载更多"继续往前看，可以一直翻到最早一轮；最底部的记录能完整看到；滚动时当前这一轮的组标题固定在顶部。
10. 看板开着时新产生的记录会出现在最上面，并短暂高亮一次；条数行跟着更新，已经看到的更早记录不会被挤掉。
11. 切到别的页签再回来，或关掉再打开看板，会重新从第一批开始显示。
12. 没有记录时，看板显示空状态提示，不显示条数行，也没有"加载更多"按钮和"没有更早的记录了"提示。

## 数据从哪来

记录来自模型在每轮结束时调用的 `goal_record` 工具。这个工具调用的三个字段（问题、方案、成果）会被会话日志持久保存；看板从日志中派生出列表，不写入第二份存储。因此刷新、分叉或重放会话后，记录仍然可以从日志重建。记录列表仍然一次发给浏览器，分批显示只影响页面上画多少行，不改日志、投影格式和 `goal_record` 工具。

只有三个字段都非空、且目标处于活动状态的轮次才会出现在看板上。

## 关闭插件后

关闭插件不会删除任何日志记录。看板页签、标题栏按钮和 `goal_record` 工具会一并消失；重新启用后，过去的记录会从日志重新显示出来。

## 字体与图标

界面继承 DSH 的主题变量，不打包任何字体文件。插件图标为原创图形。
